# Okuryazmaz

Yeni nesil edebiyat ve kitap forumu. Node.js, Express ve SQLite ile yazıldı.

## Kurulum

```bash
npm install
cp .env.example .env   # JWT_SECRET'e uzun rastgele bir değer yazın
npm start
```

Veritabanı (`database/okuryazmaz.db`) ilk çalıştırmada otomatik oluşturulur.
`GEMINI_API_KEY` tanımlanırsa yapay zeka özellikleri açılır.
